# 기능 명세: Capture Control UX

**Feature Branch**: `chore/kotlin-style-lint`

**작성일**: 2026-09-08

**상태**: 초안

**입력**: Session 목록에서 새 수집을 시작하고, 전체 화면 카메라 프리뷰에서 재생·일시 정지·정지 아이콘으로 Session과 Episode를 제어하는 UI/UX를 제공한다.

## 목표

수집자는 Session 목록에서 새 수집을 시작하고, 카메라 프리뷰가 중심인 전체 화면 작업 공간에서 익숙한 미디어 제어 아이콘만으로 수집을 조작한다. 사용자는 Episode라는 내부 데이터 단위를 별도로 조작할 필요 없이 재생, 일시 정지, 정지의 의미로 연속 수집과 작업 구간을 구분할 수 있어야 한다.

## 사용자 시나리오 및 테스트 *(필수)*

### 사용자 스토리 1 - Session 목록에서 새 수집 시작 (우선순위: P1)

수집자는 기존 Session의 상태를 목록에서 확인하고, 새 수집을 선택해 카메라 프리뷰가 있는 전체 화면 수집 작업 공간으로 진입한다.

**우선순위 근거**: 수집 시작점과 기존 데이터 관리를 분리해야 사용자가 현재 작업 대상과 수집 상태를 혼동하지 않는다.

**독립 테스트**: 완료·미전송·실패 상태의 Session이 있는 목록에서 새 수집을 선택하고, 전체 화면 작업 공간과 시작 가능한 프리뷰 상태를 확인한다.

**인수 시나리오**:

1. **Given** Session 목록 화면, **When** 수집자가 새 수집을 선택하면, **Then** 전체 화면 수집 작업 공간이 열리고 목록 조작은 노출되지 않는다.
2. **Given** 수집 준비가 완료된 작업 공간, **When** 수집자가 화면을 보면, **Then** 카메라 프리뷰와 재생 아이콘을 확인할 수 있다.
3. **Given** 카메라 또는 수집 준비가 불가능한 작업 공간, **When** 수집자가 진입하면, **Then** 원인과 다음 행동을 알 수 있으며 재생 조작은 시작되지 않는다.

---

### 사용자 스토리 2 - 아이콘으로 연속 수집과 Episode 구간 제어 (우선순위: P1)

수집자는 텍스트 버튼 대신 재생, 일시 정지, 정지 아이콘을 사용해 수집을 시작하고, 작업 구간을 나누며, 전체 Session을 끝낸다.

**우선순위 근거**: 수집 중에는 카메라 프리뷰와 현재 상태를 빠르게 인지하고 한 손으로 조작할 수 있어야 한다.

**독립 테스트**: 준비된 수집 화면에서 재생, 일시 정지, 재생, 정지 순서로 조작하고 Session 및 두 Episode의 시간 경계를 확인한다.

**인수 시나리오**:

1. **Given** 준비된 수집 화면, **When** 수집자가 재생 아이콘을 누르면, **Then** 새 Session 수집과 첫 작업 구간이 함께 시작되고 화면은 수집 중 상태가 된다.
2. **Given** 작업 구간이 진행 중인 수집 화면, **When** 수집자가 일시 정지 아이콘을 누르면, **Then** 현재 작업 구간만 종료되고 Session의 카메라·센서 수집은 계속된다.
3. **Given** 작업 구간이 종료됐지만 Session 수집은 계속되는 화면, **When** 수집자가 재생 아이콘을 누르면, **Then** 다음 작업 구간이 시작된다.
4. **Given** 수집 중인 화면, **When** 수집자가 정지 아이콘을 누르면, **Then** 열린 작업 구간을 종료하고 Session 수집을 종료·확정한다.

---

### 사용자 스토리 3 - 수집 상태를 프리뷰 위에서 인지 (우선순위: P2)

수집자는 프리뷰를 보면서 현재 Session 수집 상태와 작업 구간 상태를 즉시 구분하고, 실수로 수집을 종료하지 않는다.

**우선순위 근거**: 수집 중단 또는 구간 누락은 이후 데이터의 활용성을 떨어뜨린다.

**독립 테스트**: 준비, 작업 구간 진행, 작업 구간 종료 후 Session 유지, Session 확정 중의 화면을 비교해 노출된 상태와 조작 가능 여부를 확인한다.

**인수 시나리오**:

1. **Given** 수집 화면의 모든 상태, **When** 수집자가 프리뷰를 보면, **Then** Session 수집 여부와 현재 작업 구간 여부를 텍스트·아이콘·색상으로 함께 알 수 있다.
2. **Given** 작업 구간 진행 중, **When** 수집자가 정지 아이콘을 누르면, **Then** 전체 수집 종료임을 확인할 기회가 제공된다.
3. **Given** 수집 중, **When** 수집자가 뒤로 가기 또는 화면 닫기를 시도하면, **Then** 의도치 않은 종료를 방지할 확인 절차가 제공된다.

### 엣지 케이스

- 수집 준비 중 카메라 권한, AR 추적 또는 저장소 조건이 충족되지 않으면 재생 아이콘은 수집을 시작하지 않으며 필요한 조치를 안내한다.
- Session 확정 중에는 중복 입력으로 새 작업 구간이나 두 번째 종료가 시작되지 않는다.
- 작업 구간이 없는 상태에서 정지하면 Session은 정상 종료할 수 있다.
- 수집 중 화면이 예기치 않게 중단되면, 사용자는 다음 진입 시 해당 Session이 완료되지 않았음을 식별할 수 있다.
- 목록에 Session이 없을 때는 빈 상태와 새 수집 시작 행동을 함께 제공한다.

## 요구사항 *(필수)*

### 기능 요구사항

- **FR-001**: 시스템은 Session 목록에서 각 Session의 식별 가능한 요약과 현재 수집·내보내기·업로드 상태를 표시해야 한다.
- **FR-002**: 시스템은 새 수집을 선택하면 카메라 프리뷰 중심의 전체 화면 수집 작업 공간을 열어야 한다.
- **FR-003**: 시스템은 준비 상태에서 재생 아이콘으로 새 Session과 첫 작업 구간을 함께 시작해야 한다.
- **FR-004**: 시스템은 작업 구간 진행 중 재생·일시 정지·정지의 표준 시각 아이콘을 사용해야 하며, 텍스트 버튼을 주 제어 수단으로 사용하지 않아야 한다.
- **FR-005**: 시스템은 일시 정지 아이콘을 누르면 현재 작업 구간만 종료하고 Session의 연속 원시 데이터 수집은 유지해야 한다.
- **FR-006**: 시스템은 작업 구간이 없는 수집 상태에서 재생 아이콘을 누르면 다음 작업 구간을 시작해야 한다.
- **FR-007**: 시스템은 정지 아이콘을 누르면 전체 Session을 종료·확정하고, 열린 작업 구간이 있으면 함께 종료해야 한다.
- **FR-008**: 시스템은 수집 중·작업 구간 진행 중·작업 구간 종료 후 수집 유지·확정 중 상태를 명확히 구분해 표시해야 한다.
- **FR-009**: 시스템은 정지, 뒤로 가기, 화면 닫기처럼 Session을 끝낼 수 있는 행동 전에 사용자가 결과를 확인할 기회를 제공해야 한다.
- **FR-010**: 시스템은 아이콘만 보이는 조작에도 보조 기술과 도구 설명에서 동작 의미를 전달해야 한다.
- **FR-011**: 시스템은 Session 확정이 끝나면 해당 Session의 상세 또는 목록으로 돌아가 확정 결과를 확인할 수 있게 해야 한다.
- **FR-012**: 이 기능은 기존 Session·Episode 데이터 형식, 내보내기 및 업로드 계약을 변경하지 않아야 한다.

### 핵심 엔터티

- **Session**: 카메라, 센서, 자세 데이터를 연속으로 보관하는 하나의 수집 단위. 목록의 한 항목이며 정지로 종료·확정된다.
- **Episode**: Session 안에서 재생부터 일시 정지 또는 정지까지의 작업 구간. UI에서는 내부 용어로 전면 노출하지 않는다.
- **수집 작업 공간**: 카메라 프리뷰, 수집 상태, 시각 제어 아이콘을 제공하는 전체 화면 맥락이다.

## 성공 기준 *(필수)*

### 측정 가능한 결과

- **SC-001**: 수집자는 Session 목록에서 세 번 이하의 직접 조작으로 새 수집 화면을 열고 첫 작업 구간을 시작할 수 있다.
- **SC-002**: 준비, 작업 구간 진행, 작업 구간 종료 후 수집 유지의 세 상태를 각 상태 화면만 보고 올바르게 구분할 수 있다.
- **SC-003**: 재생·일시 정지·정지 순서로 조작한 10회의 시험에서 Session 하나와 의도한 작업 구간 경계가 매번 하나씩 기록된다.
- **SC-004**: 수집 중 뒤로 가기 또는 종료 조작의 100%에서 의도치 않은 Session 종료 전 확인 기회가 제공된다.
- **SC-005**: 화면에 보이는 아이콘만으로도 보조 기술 사용자가 각 제어의 목적을 구분할 수 있다.

## 가정

- 기존에 정의된 Session, Episode, 라벨 및 데이터 무결성 규칙은 유지한다.
- 재생은 준비 상태에서는 새 Session과 첫 Episode를 시작하고, Episode가 종료된 수집 상태에서는 다음 Episode를 시작한다.
- 정지는 열린 Episode가 있으면 그 시점에 종료한 뒤 Session을 확정한다.
- 카메라 프리뷰는 수집자가 기기 방향과 관찰 대상을 확인하는 용도이며, Session에 보관되는 원본 영상 계약을 대체하지 않는다.
- 이번 범위는 수집 화면과 Session 목록 UX이며, 내보내기·업로드 프로토콜 및 서버 동작 변경은 포함하지 않는다.
